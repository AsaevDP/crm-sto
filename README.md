# CRM для СТО

Локальная CRM для автосервиса на 10 подъёмников: приёмка с фото → диагностика → согласование → запчасти и склад → ремонт → оплата → выдача авто. Плюс разбор (б/у запчасти), зарплата сотрудников в процентах, учёт присутствия по картам.

Работает **без интернета**, в локальной сети СТО. Доступ с iPhone и Windows-ПК через браузер.

## Запустить у себя (Windows)

Нужен Python 3.11+.

1. Скачать проект: зелёная кнопка **Code → Download ZIP**, распаковать.
2. Запустить `run.bat`. В первый раз он сам установит всё нужное.
3. Откроется `http://localhost:8810`. Тестовые входы — [docs/test-users.md](docs/test-users.md).
