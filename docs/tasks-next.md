# Задачи на следующий раз (продиктованы 21.11.2026, брат) — начать с них

Порядок работы как обычно: как понял → вопросы → план → «го».

## 1. «Запись»: записывать клиентов — только менеджер, директор, зам, админ

- Сейчас в «Записи» блок «Новая запись» видят все, у кого есть раздел: слесарь, электрик, моторист, мойщик.
  Мастера сами себе записи не делают — это обязанность менеджера.
- **Убрать «Новую запись» у ВСЕХ, кроме менеджера, директора, зама и админа** — не только у мастеров (слесарь, электрик,
  моторист, мойщик, детейлер), а у любой должности, у которой есть «Запись» (кладовщики, запчастист, бухгалтер и т. д. —
  проверить по ролям). Остальные только смотрят.
- **Директору и заму — кнопку «Записать» и весь функционал записи, как у менеджера** (сейчас у директора её нет).
- Проверить права `schedule.manage` / `schedule.view` по ролям, «Напомнить о записи» — тоже у этих четырёх.

## 2. «Загрузка мастеров» — на «Пульт»

- В «Записи» (день / неделя) есть окошко «Загрузка мастеров» — очень полезное.
- **Перенести на «Пульт»**: серая кнопка «Загрузка мастеров» рядом с «Приёмкой» и «🔑 Ячейки ключей».
- Внутри — **такая же диаграмма, только ярче, красочнее и понятнее**.
- Видят: менеджер, директор, зам, админ.
- Уточнить у брата: в «Записи» окошко оставить или убрать совсем («переместить»).
