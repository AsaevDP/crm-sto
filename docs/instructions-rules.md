# Правила для будущих инструкций пользования CRM

Сюда записываем порядок работы СТО, который в CRM **не отображается**, но обязательно должен войти в инструкции
для сотрудников (менеджеров, мастеров и т. д.). Когда будем делать инструкции — пройти этот список целиком.

## 1. Бумаги по машине и выдача только по акту приёма (21.11.2026, брат)

**Кто:** менеджер (основное), мастер.

1. **Приезд клиента — Акт приёма автомобиля в двух экземплярах.**
   - Один отдают клиенту, второй остаётся на СТО.
   - Экземпляр СТО заполняют одним из двух способов:
     - менеджер заполняет от руки, потом переносит в CRM;
     - мастер сразу заполняет в CRM.
   - Бумагу СТО закрепляют на пластиковом планшете с зажимом (как у выступающего на сцене) — он едет вместе с машиной.
2. **Заказ-наряд — тоже в двух экземплярах.**
   - Один в итоге отдают клиенту вместе с Актом выдачи, второй остаётся на СТО.
3. **Акт выдачи — в двух экземплярах.**
   - Один отдают клиенту, второй остаётся на СТО.
4. **Машину выдаём только тому, у кого на руках Акт приёма** (экземпляр клиента).
   - Это подтверждение, что машину забирает тот же человек, который её сдал.
   - Важно, когда за машиной приходит не владелец из техпаспорта: знакомый, друг, жена / муж.
   - Это обязательная предосторожность для менеджера.

**В CRM это никак не показываем** (решение владельца) — только в инструкции.
