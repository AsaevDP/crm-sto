# Резервные копии базы (с 11.11.2026)

## Что делает CRM сама
- При каждом запуске — копия базы **до** любых изменений: `data/backups/crm-ГГГГ-ММ-ДД_ЧЧ-ММ-СС-start.db`.
- Пока CRM работает — раз в сутки ещё одна: `…-daily.db`.
- Хранятся последние 14 копий, старые удаляются сами.
- Копия делается встроенным способом SQLite (backup) — он забирает и то, что ещё не перенесено из `crm.db-wal`.
  **Нельзя** просто скопировать файл `crm.db` при работающей CRM: пропадут последние записи
  (тестировщик проверил: из 15 оплат пропала 1).

## Как восстановить
1. Остановить CRM (закрыть окно `run.bat`).
2. Переименовать текущий `data/crm.db` в `crm-сломанная.db` (на всякий случай), удалить `crm.db-wal` и `crm.db-shm`.
3. Скопировать нужную копию из `data/backups/` в `data/` и назвать `crm.db`.
4. Запустить `run.bat`.

## Чего пока нет (шаг 8)
- Копии на другой диск / в облако — если умрёт диск ПК, копии умрут вместе с ним.
  До шага 8: раз в неделю копировать папку `data/backups` на флешку.

## Второй уровень — архив клиентов Excel + JSON (с 25.11.2026)
- Папка на каждого клиента: `data/archive/clients/К-00012 Имя/` (можно указать другую папку — «Настройки → Архив клиентов»):
  `Клиент.xlsx` (прочитать глазами), `данные.json` (точная копия строк базы по клиенту), `фото машин/`.
  В корне — `_Список клиентов.xlsx` и `КАК ВОССТАНОВИТЬ.txt`.
- Обновляется каждую ночь после 2:00 (`services/nightly.py`, отметка `data/nightly.txt`) и кнопкой «Обновить сейчас».
  Файл клиента переписывается, только если что-то изменилось.
- «⬇ Скачать архив (zip)» — для флешки. Восстановление: «Настройки → Архив клиентов → Проверить → Восстановить»
  (`services/client_archive.restore`): добавляет только то, чего нет (по id), повторно — без дублей; перед этим копия базы.
- Возвращает: клиентов, телефоны, машины, наряды, работы, запчасти, проблемы, оплаты, события клиента, историю наряда.
  Склад, закупки, зарплату, табель, инструмент — НЕ возвращает (это копии базы из `data/backups`).
- Видит только владелец (право `data.archive`, по умолчанию — админ). Подробности для владельца — в его отдельной инструкции.

## Фото (с 25.11.2026)
- Все фото — `data/photos/` (на сервере — общая папка). «Настройки → Фотоархив»: сколько места, по нарядам / машинам /
  складу и разбору / инструменту.
- Фото нарядов удаляются сами через срок хранения (по умолчанию 365 дней, только закрытые и отменённые наряды).
  Закреплённое фото машины (`data/photos/cars/`) — хранится всегда. Удалить вручную и менять срок — только админ.
