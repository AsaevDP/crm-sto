# Обо мне

- Я не программист. Веду свою СТО и делаю для неё CRM вместе с Claude.
- Общайся на русском: коротко, списками, без жаргона. Если без термина не обойтись — объясни в одну строку.
- Команды запускай сам, не проси меня ничего набирать в терминале. Если без меня никак
  (войти в аккаунт, нажать кнопку на сайте) — напиши по шагам: куда нажать и что увидеть.
- Задача больше одного шага → как понял (2–3 строки) → вопросы → план «шаг → как проверим» → жди моего «го».
- Результат показывай: открой страницу в браузере Claude, сделай скриншот. Не проси меня проверять самому.
- Перед работой над проектом забирай свежую версию (`git pull`), после — предложи залить.
- Ничего не удаляй и не заливай в интернет без моего «да».
