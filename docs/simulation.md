# «Живая» проверка CRM (12.11.2026)

`scripts/simulate.py` проживает **6 недель работы СТО** день за днём. Каждое действие — **та же кнопка, что у человека**:
скрипт входит под нужным сотрудником и отправляет ту же форму (те же права, проверки и сообщения). Напрямую в базу
ничего не пишется — только перенос времени: всё, что сделано «за день», сдвигается на этот день в прошлом.

Не сработала кнопка (ошибка сервера, отказ в доступе, красное сообщение) или после действия получилось не то, что
должно, — это строка в отчёте `data/sim/report.md`. Отчёт сначала смотрит владелец, чинится — после его «да».

Сотрудники — те же (docs/test-users.md). Клиенты, машины, наряды, закупки, деньги, зарплата — заново.

## Кто что делает

| Кто | Что нажимает |
|---|---|
| Админ | заводит сотрудников, карты, пары менеджер ↔ запчастист, посты, ячейки склада, шкафы инструмента, схемы зарплаты; увольняет Романа |
| Менеджер (Ирина, Марина) | запись клиента → приёмка (фото, топливо, вещи) → на диагностику или проблемы со слов клиента → согласование (да / отказ) → цены работ, исполнители → варианты запчастей на выбор → оплата → выдача авто; возврат денег, отмена, «открыть заново», доступ к чужому клиенту, передача наряда, сообщения |
| Слесарь, автоэлектрик, моторист | закрепиться за постом → диагностика (находки с фото) → «Готово» → «Срочно» на детали → «Запросить выдачу» → Начал / Пауза (с причиной) / Выполнено → просит запчасть со склада, инструмент, сдаёт его |
| Мойщик, детейлер | свои работы в наряде (Начал / Выполнено), просит химию |
| Запчастист (Олег, Василий, Денис, Юрий) | подбор: со склада / заказать / с запасом → черновик закупки → «✓ Заказал» с датой «привезут» |
| Кладовщик (Павел) | «Привезли» → «Принять полностью» или «Неполная поставка» → «Готово к выдаче» / «Выдано» → инструмент «Выдать» / «Принял» → химия «Выдать» / «Отказать» → инвентаризация → проверка инструмента |
| Контентщик (Дмитро) | донор → детали списком → продажа: резерв → упаковано → отправлено (ТТН) → получено / возврат; списание |
| Бухгалтер (Оксана) | неделя зарплаты: проверил каждого → (директор / админ утверждает) → выдал |
| Директор, зам | решают запросы доступа и «открыть заново», аванс, закупка химии (зам) |
| Все | приход / уход по карте (табель) |

## Неудачные сценарии (≈10–15 %)

клиент отказался от части работ · поставщик привёз не всё · деталь не подошла — вернули на склад · отказ в химии ·
возврат денег клиенту · отмена наряда (с деньгами и без) · «открыть заново» · инструмент сломан / потерян → удержание ·
менеджер просит доступ к чужому клиенту · передача наряда другому менеджеру · пауза с причиной · новая проблема во время ремонта.

## Проверки после прогона (логика)

остатки не уходят в минус и сходятся с движениями · у выданных машин оплачено ровно «Итого» · у каждой выполненной
работы есть начисление исполнителю · выданная химия списана, в счёт не попала · недели зарплаты: начислено = выдано ·
у закрытых закупок всё принято · каждый экран каждого сотрудника открывается без ошибки.
