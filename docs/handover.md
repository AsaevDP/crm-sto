# Как начать работу над CRM на своём ПК

Проект передан 09.11.2026. Всё, что нужно Claude, лежит в самом проекте:
`CLAUDE.md` (правила и статус), `BRIEF.md` (полное ТЗ), `docs/next-tasks.md` (последние правки),
`docs/test-users.md` (тестовые входы). Claude прочитает их сам.

## Быстрый старт — одно сообщение
Поставить приложение **Claude** (с подпиской), открыть вкладку **Code**, выбрать любую папку
(например, создать `C:\Projects`) и отправить Claude это сообщение целиком:

> Я не программист, общайся по-русски, коротко, списками, команды запускай сам. Подготовь мне ПК для проекта CRM:
> 1. Проверь, есть ли Git и Python 3.11; если нет — поставь через winget (`Git.Git`, `Python.Python.3.11`).
> 2. Склонируй https://github.com/AsaevDP/crm-sto в эту папку.
> 3. Настрой Claude по `crm-sto/docs/claude-setup/README.md` (все шаги, кроме тех, что руками в приложении).
> 4. Запусти CRM, войди admin / admin123 и покажи скриншот.
> 5. В конце скажи, что мне сделать руками (режим Auto, открыть папку `crm-sto` в Claude и т. п.).

После этого открыть в Claude папку `crm-sto` и работать в ней. Ниже — то же самое по шагам, если что-то не пошло.

## 1. Установить (один раз)
1. **Git** — git-scm.com → Download for Windows, всё по умолчанию.
2. **Python 3.11** — python.org → Downloads → Python 3.11.x. При установке поставить галочку **«Add python.exe to PATH»**.
3. **Claude** (приложение для ПК) с подпиской — вкладка **Code**.
4. Аккаунт на **GitHub** (github.com) — чтобы заливать изменения.

## 2. Забрать проект
В Claude (вкладка Code) выбрать папку, например `C:\Projects`, и написать:

> Склонируй https://github.com/AsaevDP/crm-sto в эту папку и открой проект

Потом открыть в Claude папку `crm-sto` — дальше работать в ней.

## 3. Настроить Claude «как у Стаса»
Открыть папку `crm-sto` в Claude и написать:

> Настрой Claude на этом ПК по docs/claude-setup/README.md

Claude сам поставит личные правила (общение по-русски, коротко, без программистских просьб), навык дизайна,
разрешения на частые команды и просмотр CRM прямо в Claude. На каждый шаг спросит разрешение — отвечать «да».

## 4. Секретный файл `.env`
Его нет на GitHub (там ссылка для обновления демо). Получить от Стаса **в личке** и положить в корень проекта
рядом с `run.bat`. Без него всё работает, только демо на Render не обновится после заливки.

## 5. Запуск
- Двойной клик по `run.bat` — сам поставит всё нужное, CRM откроется на `http://localhost:8810`.
- Или попросить Claude: «запусти CRM и покажи».
- Входы — в `docs/test-users.md` (например, admin / admin123). База создаётся сама с примерами.

## 6. Как работать
- Пишите Claude по-русски, что хотите поменять. Он сначала расскажет, как понял, задаст вопросы и предложит план;
  делает после «го».
- Перед началом работы: «забери свежую версию» (`git pull`) — если кто-то ещё правил проект.
- Залить изменения и обновить демо: «залей на демо» (Claude запустит `bash scripts/push.sh`).
  Демо: https://crm-sto-demo.onrender.com — обновляется через 3–5 минут. Если демо долго открывается,
  оно «спит» (бесплатный Render) — подождать минуту.

## Что осталось на ПК Стаса и не переезжает
- Доступ через Tailscale (раздел «Удалённый доступ» в `CLAUDE.md`) — это про ПК Стаса.
- Аккаунт Render и сам репозиторий — пока у Стаса (`AsaevDP`). Чтобы заливать, Стас добавляет брата:
  GitHub → crm-sto → Settings → Collaborators → Add people. Позже репозиторий можно перенести на аккаунт брата
  (Settings → Transfer ownership) — старые ссылки GitHub перенаправит сам.
