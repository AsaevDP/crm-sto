## 2. Запись на мастера и время
- Запись клиента **заранее**: дата, время, мастер (и/или подъёмник), длительность.
- Календарь/сетка по мастерам на день и неделю; занятые слоты видны, двойная запись — предупреждение.
- Из записи в день приезда — одной кнопкой создать наряд (или привязать к существующему).
- Статусы записи: записан → приехал → не приехал / отменён.
- Вопросы: шаг сетки (30 мин? час)? Запись на мастера или на подъёмник? Нужно ли напоминание клиенту (пока без SMS — внешних запросов нет)?

## 3. Выполнение работ: кнопка + индикация
- У слесаря в наряде у каждой работы — кнопка «Выполнено» (и отмена).
- У менеджера то же + видно, кто и когда отметил.
- На карточке/строке каждой машины — полоска прогресса по цвету:
  красная (ничего не сделано) → оранжевая (частично) → зелёная (всё выполнено).
- Вопросы: пороги цвета (0% / 1–99% / 100%) или больше ступеней (жёлтый)?

## 4. Печать
- Кнопка «Печать» на документах: наряд-заказ, акт приёма, акт выполненных работ, счёт, при необходимости — ведомость зарплаты.
- Отдельная страница для печати (A4, ч/б, без меню), печать через браузер. Без внешних сервисов.
- Идея «папки»: на клиента — пакет всех его документов для печати; на сотрудника — его документы.
- Вопросы: какие документы печатать в первую очередь? Нужны ли реквизиты СТО, подписи, печать в шапке?

## 5. Склад: две основные категории

## 8. Директор и замдиректора
- Новые роли: **директор**, **заместитель директора** (в `permissions.py`, права по умолчанию).
- У каждой роли свой кабинет (главная): отчёты, графики, сводные таблицы, квартальные отчёты, бухгалтерия:
  выручка/расходы/прибыль по периодам, зарплатный фонд, склад (оборот, остатки в деньгах), закупки, разбор, загрузка мастеров.
- Графики — локальной библиотекой из `app/static/` (без CDN).
- Выгрузка таблиц в Excel/CSV.
- Вопросы: чем кабинет директора отличается от замдиректора? Какие 3–5 отчётов нужны прежде всего? «Директор сотрудничества» — это опечатка («директор» + «замдиректора») или отдельная должность?
